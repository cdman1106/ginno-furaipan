# 洋食や 銀のフライパン

スマホ・PC向けの静的サイトです。料理・店内・外観の写真8枚を含みます。

## 写真

依頼者より、Instagramおよび紹介記事の写真についてすべて使用許可を取得済みとの確認を受けています。今回の写真取得元は紹介記事です。

出典：https://mrs.living.jp/fukuoka/newopen/reporter/6913020

## 配置

`dist` が静的サイトの公開フォルダです。Cloudflare Pages等では公開ディレクトリを `dist` に指定します。GitHub Pagesのブランチ方式ではルートまたは docs を使うため、dist の内容の移動、またはActionsによる公開設定が別途必要です。

サイトの一般公開設定はまだ実施していません。公開前に店舗情報の最終確認と実画面での表示確認を行ってください。
