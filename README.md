# 洋食や 銀のフライパン — サイト制作案

スマホ・PC向け静的サイトのコードです。現時点では未公開の制作途中版です。

## 写真について

HTML/CSSが参照する写真は、このリポジトリには含めていません。前段階で参照した紹介記事の写真は転載許可を確認できていないためです。店舗が使用を許可した写真を `dist/assets/` に配置してから公開してください。現状のままでは写真は表示されません。

## 公開前の確認

- 店舗の掲載・公開承認と写真の使用許可
- 住所・営業時間・電話番号・メニューの最終確認
- スマホ・PCでの表示確認

## 配置

`dist` が静的サイトの公開フォルダです。Cloudflare Pages等では公開ディレクトリを `dist` に指定します。GitHub Pagesのブランチ方式では公開元にルートまたは docs を使うため、dist の内容の移動、またはActionsによる公開設定が別途必要です。
